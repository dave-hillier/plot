# Getting started

Replot supports a variety of environments, including a first-class [React component API](#plot-in-react) for building charts with declarative JSX.

## Try it online {/* {#try-plot-online} */}

A quick way to try the Observable Plot API online is on [Observable](https://observablehq.com), where **Observable Plot** — the library Replot is forked from — is available by default in notebooks as part of Observable’s standard library. Replot’s imperative API is compatible, so code you sketch there carries over. To use Observable Plot in a notebook, simply return the generated plot from a cell like so:

<Replot>
  <BinX y="count">
    <RectY data={{length: 10000}} x={d3.randomNormal.source(d3.randomLcg(42))()} />
  </BinX>
</Replot>

Observable includes a variety of Observable Plot snippets when you click **+** to add a cell, as well as convenient [sample datasets](https://observablehq.com/@observablehq/sample-datasets) to try out Observable Plot features. Or upload a CSV or JSON file to start playing with your data. You can even use [Observable’s chart cell](https://observablehq.com/@observablehq/chart-cell), which uses Observable Plot’s [auto mark](./marks/auto.md) under the hood, to create quick charts without writing code! You can then eject to JavaScript by clicking **+** to see the equivalent Observable Plot code.

## Replot in vanilla HTML {/* {#plot-in-vanilla-html} */}

In vanilla HTML, you can load Replot from a CDN such as jsDelivr or you can download it locally. We recommend using the CDN-hosted ES module bundle as it automatically loads Replot’s dependency on [D3](https://d3js.org). But for those who need it, we also provide a UMD bundle that exports the `Replot` global when loaded as a plain script.

```html [ESM + CDN]
<!DOCTYPE html>
<div id="myplot"></div>
<script type="module">

import * as Replot from "https://cdn.jsdelivr.net/npm/replot@0.6/+esm";

const plot = Replot.rectY({length: 10000}, Replot.binX({y: "count"}, {x: Math.random})).plot();
const div = document.querySelector("#myplot");
div.append(plot);

</script>
```

```html [UMD + CDN]
<!DOCTYPE html>
<div id="myplot"></div>
<script src="https://cdn.jsdelivr.net/npm/d3@7"></script>
<script src="https://cdn.jsdelivr.net/npm/replot@0.6"></script>
<script type="module">

const plot = Replot.rectY({length: 10000}, Replot.binX({y: "count"}, {x: Math.random})).plot();
const div = document.querySelector("#myplot");
div.append(plot);

</script>
```

```html [UMD + local]
<!DOCTYPE html>
<div id="myplot"></div>
<script src="d3.js"></script>
<script src="plot.js"></script>
<script type="module">

const plot = Replot.rectY({length: 10000}, Replot.binX({y: "count"}, {x: Math.random})).plot();
const div = document.querySelector("#myplot");
div.append(plot);

</script>
```
Replot returns a detached DOM element — either an [SVG](https://developer.mozilla.org/en-US/docs/Web/SVG) or [HTML figure](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/figure) element. In vanilla web development, this means you need to insert the generated plot into the page to see it. Typically this is done by selecting a DOM element (such as a DIV with a unique identifier, like `myplot` above), and then calling [*element*.append](https://developer.mozilla.org/en-US/docs/Web/API/Element/append).

If you’d prefer to run Replot locally (or entirely offline), you can download the UMD bundle of Replot along with its dependency, D3, here:

- <a href="./d3.js" download>d3.js</a>
- <a href="./plot.js" download>plot.js</a>

Then, create an `index.html` file as shown above in the **UMD + local** tab. If you prefer smaller minified files, you can download <a href="./d3.min.js" download>d3.min.js</a> and <a href="./plot.min.js" download>plot.min.js</a>, and then update the `src` attributes above accordingly.

A note on size: because the imperative `plot()` API renders through React (via `react-dom/server`), the UMD bundle ships React and is considerably larger than upstream Observable Plot’s — roughly 1 MB unminified, 426 kB minified, and 139 kB gzipped. Script-tag usage works fine, but if bundle size matters, install from npm and use a bundler instead: your application then shares a single copy of React, and unused code can be tree-shaken.

## Installing from npm

If you’re developing a web application using Node, you can install Replot via yarn, npm, pnpm, or your preferred package manager.


```bash [yarn]
yarn add replot
```

```bash [npm]
npm install replot
```

```bash [pnpm]
pnpm add replot
```

You can then load Replot into your app. For **React**, import from `replot/react`:

```js
import {Replot, Dot, Line, BarY, AxisX, AxisY} from "replot/react";
```

For the **imperative API** (vanilla JS or non-React frameworks), import from the main entry point:

```js
import * as Replot from "replot";
```

You can instead import specific symbols if you prefer:

```js
import {barY, groupX} from "replot";
```

Replot includes TypeScript declarations with extensive documentation. We highly recommend using an editor with enhanced code completion such as Visual Studio Code or Observable.

## Replot in React {/* {#plot-in-react} */}

Replot provides a first-class React component API via `replot/react`. Instead of imperatively building SVG with D3 selections, you define charts declaratively with JSX that integrates natively with React's rendering model, state management, and component lifecycle.

### Basic usage

Import the `Replot` root component and mark components, then compose them as JSX:

```jsx [App.jsx]
import {Replot, Dot, AxisX, AxisY} from "replot/react";
import penguins from "./penguins.json";

export default function App() {
  return (
    <div>
      <h1>Penguins</h1>
      <Replot width={640} height={400}>
        <Dot data={penguins} x="culmen_length_mm" y="culmen_depth_mm" fill="species" />
        <AxisX />
        <AxisY />
      </Replot>
    </div>
  );
}
```
The `<Replot>` component handles scale inference, axis generation, and layout automatically. Pass scale options as props on `<Replot>`, and channel mappings as props on mark components. Every mark available in the imperative API has a corresponding React component: `<Dot>`, `<Line>`, `<BarX>`, `<BarY>`, `<Area>`, `<Rect>`, `<Text>`, `<Rule>`, `<Tick>`, and [many more](./api.md).

### With transforms

Transforms such as binning, grouping, and stacking are available as wrapper components: nest a mark inside the wrapper, with the transform options as props on the wrapper and the input channels on the mark.

```jsx [Histogram.jsx]
import {Replot, BarY, RuleY, BinX} from "replot/react";

export default function Histogram({data}) {
  return (
    <Replot>
      <BinX y="count">
        <BarY data={data} x="value" fill="steelblue" />
      </BinX>
      <RuleY data={[0]} />
    </Replot>
  );
}
```

Transforms are also available as pure functions (`binX`, `groupX`, `stackY`, …) whose result you can spread onto a mark: `<BarY data={data} {...binX({y: "count"}, {x: "value"})} />`.
### With scale options

Configure scales by passing options directly to `<Replot>`:

```jsx [TemperatureChart.jsx]
import {Replot, Dot, RuleY} from "replot/react";

export default function TemperatureChart({data}) {
  return (
    <Replot y={{grid: true}} color={{scheme: "burd"}}>
      <RuleY data={[0]} />
      <Dot data={data} x="Date" y="Anomaly" stroke="Anomaly" />
    </Replot>
  );
}
```
### With facets

Use the `fx` or `fy` props on mark components to create small multiples:

```jsx [FacetedChart.jsx]
import {Replot, Dot} from "replot/react";

export default function FacetedChart({data}) {
  return (
    <Replot>
      <Dot data={data} x="culmen_length_mm" y="culmen_depth_mm" fx="species" />
    </Replot>
  );
}
```
### With tooltips

Add interactive tooltips with the `tip` prop on any mark, or use the `<Tip>` component for more control:

```jsx [InteractiveChart.jsx]
import {Replot, Dot} from "replot/react";

export default function InteractiveChart({data}) {
  return (
    <Replot>
      <Dot data={data} x="weight" y="height" fill="species" tip />
    </Replot>
  );
}
```
### With legends

Use the `<Legend>` component to add a legend for any scale:

```jsx [LegendChart.jsx]
import {Replot, Dot, Legend} from "replot/react";

export default function LegendChart({data}) {
  return (
    <Replot color={{legend: true}}>
      <Dot data={data} x="weight" y="height" fill="species" />
    </Replot>
  );
}
```
### Figure wrapping

Use the `title`, `subtitle`, and `caption` props on `<Replot>` to wrap the chart in a `<figure>` element:

```jsx [FigureChart.jsx]
import {Replot, Line} from "replot/react";

export default function FigureChart({data}) {
  return (
    <Replot title="Temperature over time" subtitle="Global average" caption="Source: NASA">
      <Line data={data} x="date" y="temperature" />
    </Replot>
  );
}
```
### Async data loading

Combine React's `useState` and `useEffect` with Replot components:

```jsx [AsyncChart.jsx]
import {Replot, Dot, RuleY} from "replot/react";
import * as d3 from "d3";
import {useEffect, useState} from "react";

export default function AsyncChart() {
  const [data, setData] = useState();

  useEffect(() => {
    d3.csv("/gistemp.csv", d3.autoType).then(setData);
  }, []);

  if (!data) return <p>Loading…</p>;

  return (
    <Replot y={{grid: true}} color={{scheme: "burd"}}>
      <RuleY data={[0]} />
      <Dot data={data} x="Date" y="Anomaly" stroke="Anomaly" />
    </Replot>
  );
}
```
### Imperative approach (legacy)

If you prefer the imperative API, you can still use `Replot.plot()` with `useRef` and `useEffect`:

```jsx [LegacyApp.jsx]
import * as Replot from "replot";
import {useEffect, useRef} from "react";

export default function LegacyApp({data}) {
  const containerRef = useRef();

  useEffect(() => {
    const plot = Replot.plot({
      y: {grid: true},
      marks: [
        Replot.dot(data, {x: "x", y: "y"})
      ]
    });
    containerRef.current.append(plot);
    return () => plot.remove();
  }, [data]);

  return <div ref={containerRef} />;
}
```
The declarative React component API is preferred for most applications because it integrates naturally with React's state management, avoids manual DOM manipulation, and updates automatically when your data or props change. The imperative approach generates a detached SVG element and requires manual cleanup, so it is best reserved for integrating with existing imperative code.

## Replot in Vue {/* {#plot-in-vue} */}

As with React, you can use either server- or client-side rendering with Replot and Vue.

For server-side rendering (SSR), use the [**document** plot option](./features/plots.md) to render to Vue’s virtual DOM. For example, here is a ReplotFigure component:

```js [ReplotFigure.js]
import * as Replot from "replot";
import {h} from "vue";

export default {
  props: {
    options: Object
  },
  render() {
    return Replot.plot({
      ...this.options,
      document: new Document()
    }).toHyperScript();
  }
};
```

For brevity, the virtual `Document` implementation is not shown. You’ll find it linked below.
Then, to use:

```vue [App.vue]
<script setup>
import * as Replot from "replot";
import ReplotFigure from "./components/ReplotFigure.js";
import penguins from "./assetS/penguins.json";
</script>


```
See the upstream [Observable Plot + Vue CodeSandbox](https://codesandbox.io/p/sandbox/plot-vue-jlgg2w?file=/src/App.vue) for details.

For client-side rendering, use a [render function](https://vuejs.org/guide/extras/render-function.html) with a [mounted](https://vuejs.org/api/options-lifecycle.html#mounted) lifecycle directive. After the component mounts, render the plot and then insert it into the page.

```js
import * as Replot from "replot";
import {h, withDirectives} from "vue";

export default {
  props: ["options"],
  render() {
    const {options} = this;
    return withDirectives(h("div"), [
      [
        {
          mounted(el) {
            el.append(Replot.plot(options));
          }
        }
      ]
    ]);
  }
};
```

As with React, to update your plot for whatever reason, simply render a new one and replace the old one. You can find more examples in [Observable Plot’s documentation source on GitHub](https://github.com/observablehq/plot/tree/main/docs), which uses both client- and server-side rendering for plots.

## Replot in Svelte {/* {#plot-in-svelte} */}

Here’s an example of client-side rendering in Svelte. For server-side rendering, see the upstream discussion [#1759](https://github.com/observablehq/plot/discussions/1759).

```svelte [App.svelte]
<script lang="ts">
  import * as Replot from 'replot';
  import * as d3 from 'd3';

  let div: HTMLElement | undefined = $state();
  let data = $state(d3.ticks(-2, 2, 200).map(Math.sin));

  function onMousemove(event: MouseEvent) {
    const [x, y] = d3.pointer(event);
    data = data.slice(-200).concat(Math.atan2(x, y));
  }

  $effect(() => {
    div?.firstChild?.remove(); // remove old chart, if any
    div?.append(Replot.lineY(data).plot({ grid: true })); // add the new chart
  });
</script>

<div onmousemove={onMousemove} bind:this={div} role="img"></div>
```
See the upstream [Observable Plot + Svelte REPL](https://svelte.dev/playground/e65b5c87ae7e44239cef41ec3df28f52?version=5.2.7) for details.

## Replot in Node.js {/* {#plot-in-node-js} */}

You can use Replot to server-side render SVG or PNG in Node.js. Use [JSDOM](https://github.com/jsdom/jsdom) for a DOM implementation via the **document** option, then serialize the generated plot using **outerHTML**.

```js
import {readFile} from "node:fs/promises";
import * as Replot from "replot";
import * as d3 from "d3";
import {JSDOM} from "jsdom";

const penguins = d3.csvParse(await readFile("./penguins.csv", "utf-8"), d3.autoType);

const plot = Replot.plot({
  document: new JSDOM("").window.document,
  marks: [
    Replot.dot(penguins, {x: "culmen_length_mm", y: "culmen_depth_mm", stroke: "species"})
  ]
});

plot.setAttributeNS("http://www.w3.org/2000/xmlns/", "xmlns", "http://www.w3.org/2000/svg");
plot.setAttributeNS("http://www.w3.org/2000/xmlns/", "xmlns:xlink", "http://www.w3.org/1999/xlink");

process.stdout.write(plot.outerHTML);
```

To rasterize SVG as PNG, you could use [canvg](https://github.com/canvg/canvg) and [node-canvas](https://github.com/Automattic/node-canvas), or [sharp](https://sharp.pixelplumbing.com/):

```js
process.stdout.write(await sharp(Buffer.from(plot.outerHTML, "utf-8")).png().toBuffer());
```

For better font rendering, consider [Puppeteer](https://pptr.dev/).
